# Investment Portfolio Tracker

> A full-stack portfolio tracker (stocks, crypto, savings) built as a vehicle for
> production-grade DevOps practice — containerised, provisioned with Terraform,
> deployed to Kubernetes, driven by CI/CD. Runs entirely locally, at zero cost.
